CS-Viewer

4台のノードが送り合う電波の強さから、熊が通った区間を見つけるシステムの記録を確かめるサイトです。地上局が保存したCSVを読み込むだけで、グラフの表示、データの分離、過去の版の確認ができます。

互換性

ノード・地上局・CS-Viewer のどの版どうしが一緒に使えるかをまとめました。表の版や記号を押すと、関係する所が光り、理由が下に出ます。

今の版（一式：ノード v0.6・地上局 v0.9、CS-Viewer v2.2）で、データがどう流れるかの図です。

  • 地上局は GW を通ったパケットだけを保存します（ほかのノードから直接届いた電波は、g の計測にだけ使います）。
  • GW 自身のパケットは、全員向けと地上局宛ての2通が届きますが、1件として保存します。
  • BEACON の最後の「GW の印」で、地上局の電波が届かないノードも GW を知り、時刻合わせができます。

今の版（二式：ノード v0.2・地上局 v0.2、CS-Viewer v2.2）で、データがどう流れるかの図です。

  • GW が決まるまでは、各ノードは存在通知（100ms ごと）だけを送り、ノードどうしの通信はしません。地上局は g で5秒間計測して GW を選びます。
  • 地上局は GW を通ったパケットだけを保存します（ほかのノードから直接届いた電波は、g の計測にだけ使います）。GW 自身のパケットは2通届きますが、1件として保存します。
  • 地上局の電波が届かないノードも、GW のサイクル開始を受け取って GW を知り、参加できます。

ノード（行）と地上局（列）の組み合わせです。4台のノードは必ず同じ版にしてください。

はじめての方へ

実験のデータをグラフで見るまでの流れです。

  1. CSVをPCへ移す地上局のmicroSDカードにある GS_000.csv などのファイルを、PCにコピーします。
  2. グラフ生成を開く上のメニューの「グラフ生成」を押し、CSVを枠の中にドラッグ＆ドロップします。複数まとめて読め、グラフ用と全記録は自動で振り分けます。
  3. 熊速報を確かめる一式の記録では、赤い帯が熊速報の遮蔽区間、▼が速報を受け取った時刻です。一覧を押すとその前後に拡大します。
  4. 必要なら分ける表計算ソフトで扱いたいときは「データ分離」で電波強度と熊速報のファイルに分けます。

使い方（操作と表示の説明）

比較表示では、選んだ行を横軸をそろえて縦に並べます。横軸は上の「区間・横軸」で全行共通です。縦軸は、上の「縦軸」が空欄なら行ごとに区間内の最小値−2〜最大値+2 dBm（0 は受信なしとして除き、線も切ります）。上の「縦軸」に入れると全行に、グラフの下の「行ごとの縦軸」に入れるとその行だけに効きます（行ごとの欄を空にすると元に戻ります）。ドラッグで拡大すると全行の横軸がそろって拡大され、ダブルクリックで戻ります。グラフ全体は縦2:横3で、右上の小さなボタンで大きさ（小・中・大）と背景（黒・白）を切り替え、画像としてコピー・PNG保存できます（表示の2倍の解像度）。

ドラッグで拡大、ダブルクリックで元に戻す。凡例をクリックすると線の表示・非表示を切り替えます。グラフの下の値をクリックすると、その高さに線を引きます（複数可、もう一度押すと消えます）。赤い帯は熊速報の遮蔽区間、▼は地上局が速報を受け取った時刻です。上の熊速報をクリックすると、その前後に拡大します。

「区間・横軸」の秒数は、統計の範囲とグラフの横軸の表示範囲を兼ねます。「縦軸」には dBm の下限と上限を入れます。上の欄は全部のグラフに、各グラフの下の欄はそのグラフだけに効きます。上の欄に入れた値はファイルやグラフの分け方を切り替えても保たれるので、同じ目盛りで見比べられます（臙脂色の枠が指定中の印で、「自動に戻す」で解除）。ドラッグでの拡大は一時的で、ダブルクリックすると指定した範囲に戻ります。

区間ごとの電波強度

各ノードが測った3区間の強さです（BEACON の中身）。届いたパケットを1つずつ、ミリ秒単位の時刻で並べています。赤い帯は熊速報の遮蔽区間、点線は GW が切り替わった時刻です。ドラッグで拡大すると、このページのグラフがすべて同じ範囲になります（ダブルクリックで元に戻す）。

各ノードが測った3区間の強さです（報告パケットの中身）。各値を、地上局がサイクル開始を受け取った時刻に「連番×間隔＋送ったノードのずらし」を足した時刻に並べています。受け取れなかった値（0）のところは線を切ります。点線は GW が切り替わった時刻です。ドラッグで拡大すると、このページのグラフがすべて同じ範囲になります（ダブルクリックで元に戻す）。

グラフの部品を読み込めませんでした（インターネット接続を確かめてください）。集計と一覧はそのまま使えます。

取りこぼしの集計

各ノードの BEACON には1ずつ増える番号（seq）が入っています。番号が飛んだところを、地上局まで届かなかったパケットとして数えます。時刻合わせで番号が0に戻ったところは、戻った後の抜けだけを数えます。

二式では、サイクル番号ごとに各ノードが送るはずの検出用パケット（初期設定は8回）と報告パケット（1回）のうち、地上局の記録にないものを数えます。ノードがサイクル開始を受け取れずに送らなかった分も、取りこぼしに含まれます。

      MACアドレス

      このシステムで使うマイコンのMACアドレス帳です。最新のMACアドレスはここで管理します。

      MACアドレスとは

      ネットワークにつながる機器が1台ずつ持っている、住所のような番号です。80:f1:b2:64:2f:d4 のように、2けたの英数字（16進数）6組をコロン（:）でつないで書きます。

      ノードどうしの通信（ESP-NOW）では、この番号で「どの機体から届いた電波か」を見分けます。プログラムに書いた番号が1文字でも違うと、その機体の電波は無視されてしまいます。

      ESP32 には「Wi-Fi STA 用」と「SoftAP 用」の2つのMACアドレスがあります。このシステムで使うのは STA 用です（SoftAP 用は最後の数字が1だけ大きいので、取り違えに注意してください）。

      使い方

      1. MACアドレスを調べる新しいマイコンを Thonny につなぎ、次のプログラムを実行すると、シェルにMACアドレスが表示されます。 
        import network, binascii
sta = network.WLAN(network.STA_IF)
sta.active(True)
sta.disconnect()
print(binascii.hexlify(sta.config('mac'), ':').decode())
      2. 表に登録する下の「編集する」を押して行を追加・変更し、「変更を保存」を押します。保存されたファイルを GitHub に push すると、全員の画面に反映されます。
      3. プログラムに書き込むいちばん下の「プログラム用のコピー」で、ノードA〜Dと地上局に使う機体を選び、できた文をコピーして main.py（4台とも同じ）と gs_main.py の MACS の部分に貼り付けます。NODE_ID は機体ごとに変えます。

      1. 保存したファイルで、GitHub の cs-viewer にある同じ名前のファイルを置き換えて push します（Claude に頼む場合は「MACアドレスを変えたファイルを push して」と伝えてください）。
